## E-commerce UI Clone
 A front-end practice project inspired by Amazon's homepage layout.
## Features
 Static layout with category sidebar, hero banner placeholder, and product grid cards styled with CSS.
## Technologies Used
 HTML5, CSS3.
## Structure
 index.html main page, amazon.css styling, images/ folder for all images.
## How to Use Clone this repo,
 open index.html in your browser, no build tools required.
